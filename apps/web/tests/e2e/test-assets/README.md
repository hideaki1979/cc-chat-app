# テスト用ファイル

このディレクトリには、E2Eテストで使用するテスト用ファイルを配置します。

## 必要なファイル

### test-image.jpg
- サイズ: 小さな画像ファイル（1KB - 1MB程度）
- 形式: JPEG
- 用途: ファイル添付機能のテスト

### large-file.exe
- サイズ: 大きなファイル（制限を超えるサイズ）
- 形式: サポートされていない形式
- 用途: ファイル形式・サイズ制限のテスト

## ファイル作成方法

```bash
# テスト用画像ファイルを作成（macOS/Linux）
cd apps/web/tests/e2e/test-assets

# 1x1ピクセルの小さなJPEG画像を作成
echo -e '\xff\xd8\xff\xe0\x00\x10JFIF\x00\x01\x01\x01\x00H\x00H\x00\x00\xff\xdb\x00C\x00\x08\x06\x06\x07\x06\x05\x08\x07\x07\x07\t\t\x08\n\x0c\x14\r\x0c\x0b\x0b\x0c\x19\x12\x13\x0f\x14\x1d\x1a\x1f\x1e\x1d\x1a\x1c\x1c $.\' ",#\x1c\x1c(7),01444\x1f\x27=>==%\x19\x22(0GDNPJC?GE\xff\xc0\x00\x11\x08\x00\x01\x00\x01\x01\x01\x11\x00\x02\x11\x01\x03\x11\x01\xff\xc4\x00\x14\x00\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x08\xff\xc4\x00\x14\x10\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\xff\xda\x00\x0c\x03\x01\x00\x02\x11\x03\x11\x00\x3f\x00\xaa\xff\xd9' > test-image.jpg

# または、既存の小さな画像ファイルをコピー
# cp /path/to/small/image.jpg test-image.jpg

# サポートされていないファイル形式のファイルを作成
echo "This is a test executable file" > large-file.exe
```

## 注意事項

- これらのファイルはテスト専用です
- 実際のテスト実行前に適切なファイルが配置されていることを確認してください
- ファイルサイズやMIMEタイプが期待値と一致することを確認してください
